01

Profil

Développeur Full Stack .NET basé à Alger, je conçois et fais évoluer des applications web et desktop pour des environnements exigeants : cliniques et centres d'imagerie médicale, gestion de flotte, logistique de colis retour.

Mon parcours couvre l'ensemble de l'écosystème .NET : j'ai démarré sur .NET Framework et ASP.NET MVC — plus de 5 ans passés à construire et maintenir des systèmes médicaux critiques dans cet environnement — avant de migrer vers .NET Core / .NET 10, Entity Framework Core et l'architecture propre (Clean Architecture). Côté client, je travaille avec React.js et TypeScript. J'ai une expertise particulière dans l'intégration d'automates de laboratoire via les protocoles HL7 et ASTM — un domaine où la rigueur technique a un impact direct sur des dossiers patients réels.

Cette double expérience — legacy .NET Framework et .NET moderne — me permet aussi bien de reprendre et faire évoluer des systèmes existants que de concevoir des architectures neuves dans les règles de l'art.

J'aime les systèmes qui doivent tenir la charge et rester lisibles dans le temps : API bien architecturées, bases de données bien modélisées, interfaces qui ne mentent jamais à l'utilisateur.
